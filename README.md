## 🇨🇳 中文

当视频需要一个明确的动态视觉技法时使用：动态字体与标题包装、Logo 动画、口播字幕包装，TouchDesigner 风格的主体追踪框与拓扑线，或真人实拍与手绘涂鸦动画融合。主文件只判断视觉技法，确定 typography-packaging、td-cv-tracking、handdrawn-live-action 三条路线之一后，再读取对应参考文档产出设置、Prompt、生成与交付规则。一个任务默认只读一条路线，展示给用户的 Prompt 与实际用于生成的 Prompt 字符级一致。只使用真实存在的附件与用户事实，不虚构素材路径、品牌或文字。不用于静态海报设计、普通修图、完整 MV、品牌广告片或只需自然运动的普通视频。

### ✨ 能做什么

- 输入视频、Logo、图片或文字 → 输出动态字体、标题、卡片、字幕、标志处理或 AE 感版式
- 路线 typography-packaging：只追问缺失的成片画幅与时长，风格与文案直接构思展示，不追加确认轮次
- 路线 td-cv-tracking：追踪框、角标、拓扑线、点云、数字编号、扫描网格、局部负片与颜色反转
- 路线 handdrawn-live-action：真人空间与二维涂鸦产生可见接触，或在实体与手绘状态间连续变形
- 每条路线自带参考文档，作为问询、Prompt 结构、生成方式与完成条件的唯一真相源
- 保留用户指定的模型、时长、画幅、主体、文案和声音要求；弱信号不猜路线，缺决定性信息只问一次

## 🇬🇧 English

Use it when a video needs one clear motion-design technique: kinetic typography and title packaging, logo animation, talking-head caption packaging, TouchDesigner-style subject tracking boxes and topology lines, or live action blended with hand-drawn doodle animation. The main file only judges the technique; once one of the three routes — typography-packaging, td-cv-tracking, handdrawn-live-action — is fixed, it reads that route's reference for setup, prompt structure, generation, and delivery rules. A task reads one route by default, and the prompt shown to the user is character-for-character identical to the one used for generation. It works only from real attachments and user facts, never inventing asset paths, brands, or copy. Not for static poster design, ordinary photo editing, full MVs, brand ad films, or videos that only need natural motion.

### ✨ What it does

- Video, logo, image, or text in; kinetic type, titles, cards, captions, logo treatment, or AE-style layouts out
- Route typography-packaging asks only for the missing aspect ratio and duration, then proposes style and copy without extra confirmation rounds
- Route td-cv-tracking builds tracking boxes, corner marks, topology lines, point clouds, numeric IDs, scan grids, local negatives, and color inversion
- Route handdrawn-live-action makes 2D doodles visibly touch a real space, or morph continuously between physical and drawn states
- Each route ships its own reference as the single source of truth for questions, prompt structure, generation, and done criteria
- Preserves the user's model, duration, aspect ratio, subject, copy, and audio; weak signals never pick a route, and missing decisive info is asked once
